Place your photos here and update the corresponding components.

## Files to add:

| Filename            | Used in         | Description                    |
|---------------------|-----------------|--------------------------------|
| hero.jpg            | Home            | Full-width hero (couple photo) |
| welcome.jpg         | Home            | Welcome section left panel     |
| menu.jpg            | Home            | Menu section left panel        |
| entourage.jpg       | Entourage       | Page header photo              |
| directions.jpg      | Directions      | Page header photo              |

| attire.jpg          | Attire          | Page header photo              |
| gifts.jpg           | Gifts           | Page header photo              |

## To swap a photo, replace the comment in each component HTML:
```html
<!-- <img src="assets/photos/hero.jpg" alt="Arbie and Jerzey"> -->
```
Just uncomment that line and the placeholder color will be replaced by your image.

## Recommended sizes:
- Hero / page headers: 1400×600px minimum
- Venue photos: 800×600px minimum
- Attire thumbnails: 300×450px
